Cara pasang di Gmail:
1. Buka Gmail → Settings (⚙) → See all settings → General → Signature
2. Buat signature baru → klik tombol source code (<>) di toolbar
3. Paste HTML di atas → Save Changes

Cara pasang di Apple Mail:
1. Buka file ini di browser → select + copy tabel signature
2. Buka Mail → Preferences → Signatures → paste langsung

Cara pasang di Outlook:
1. File → Options → Mail → Signatures → New
2. Klik ikon HTML (<>) atau paste langsung di editor
